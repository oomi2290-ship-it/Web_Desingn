# 🏛️ Old Stones Museum - Web Design Project

## Project Overview
Welcome to the official repository for **Old Stones Museum**, a responsive multi-page website built from scratch as part of individual coursework under the guidance of Eng. Khawla Alamri. The website serves as a digital quiet place for old stories, showcasing local historical objects, ancient tools, and heritage narratives from the past.

---

## 🏛️ About the Website
* **Theme:** A historical and cultural museum dedicated to preserving ancient artifacts and stones.
* **Architecture:** Multi-page website featuring an engaging homepage, exhibits gallery, about section, and visit information pages.
* **Design Philosophy:** Minimalist, elegant, and immersive typography paired with a warm, heritage-inspired color palette.

---

## 📋 Project Requirements Checklist
This project fulfills all criteria specified by the instructor:
1. **Multi-Page Layout:** Interconnected pages including Home, Exhibits, About, and Visit info.
2. **Semantic HTML5:** Built using semantic tags like `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>`.
3. **Rich Content:** Organized headings, descriptive paragraphs, and high-quality imagery of historical items.
4. **Modern CSS Layouts:** Utilizes Flexbox and CSS Grid for structured component positioning.
5. **Font Awesome Icons:** Integrated icons for enhanced UI navigation.
6. **Interactive Hover Effects:** Smooth transitions and hover feedback on buttons and links.
7. **Advanced CSS Styling:** Includes custom animations, positioning, box shadows, pseudo-classes, and pseudo-elements.
8. **Fully Responsive:** Styled with CSS Media Queries to adapt perfectly across mobile, tablet, and desktop screens.
9. **Clean File Structure:** Neatly organized directory separating HTML files, stylesheets, JavaScript, and assets.
10. **Interactive JavaScript Features:** Custom navigation toggles, popups, image galleries/sliders, and lazy loading.

---

## ⚠️ Constraints Followed
* **Individual Work:** Completed entirely by myself as an individual assignment.
* **No Frameworks:** Developed using pure HTML5, CSS3, and JavaScript (no Bootstrap or Tailwind).
* **No Templates:** Designed completely from scratch.
* **External Stylesheets Only:** No inline or internal CSS used.
