# Web Design Project Documentation

## Project Overview
Welcome to my web design project repository! This individual project was built from scratch as part of our web design coursework under the guidance of Eng. Khawla Alamri. The goal of this assignment is to demonstrate fundamental and advanced frontend development skills using pure HTML5, CSS3, and JavaScript—completely from scratch, without relying on any external frameworks or templates.

---

## 📋 Project Requirements Checklist
Here is how the project fulfills every specific requirement outlined by the instructor:

1. **Multi-Page Architecture:** 
   * The website consists of at least four interconnected pages, allowing users to navigate smoothly between different sections of the site.
2. **Semantic HTML5:** 
   * Clean and accessible markup utilizing semantic tags such as `<header>`, `<nav>`, `<section>`, `<article>`, and `<footer>`.
3. **Rich Content Structure:** 
   * Every page is carefully structured with proper headings, informative paragraphs, and descriptive imagery.
4. **Modern CSS Layouts:** 
   * Leverages Flexbox and CSS Grid to build structured, flexible, and adaptive component layouts.
5. **Font Awesome Icons:** 
   * Integrated Font Awesome icon kits to enhance UI visual cues and navigation bars.
6. **Interactive Hover Effects:** 
   * Smooth, engaging hover animations applied across all primary buttons and navigational links.
7. **Advanced CSS Styling Techniques:** 
   * Utilizes custom animations, positioning, transitions, subtle box-shadows, pseudo-classes (`:hover`, `:focus`), and pseudo-elements (`::before`, `::after`).
8. **Responsive Media Queries:** 
   * Fully responsive design tailored using CSS Media Queries to ensure a seamless viewing experience across desktops, tablets, and mobile phones.
9. **Clean File Structure:** 
   * Organized folder hierarchy separating HTML files, stylesheets, JavaScript logic, and media assets.
10. **Interactive JavaScript Features:** 
    * Enhanced user experience with custom JavaScript implementations including mobile navigation toggles, interactive popups, an image slider, and lazy loading.

---

## ⚠️ Important Constraints & Rules Followed
* **Strictly Individual Work:** Built entirely by myself as an individual assignment (no group work).
* **No CSS Frameworks:** Zero reliance on Bootstrap, Tailwind, or similar libraries.
* **No Pre-made Templates:** Designed and coded from scratch.
* **External CSS Only:** No inline or internal CSS styles were used; everything is neatly organized in external style sheets.
